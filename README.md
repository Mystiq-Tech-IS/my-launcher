# MyLauncher

**Современный игровой лаунчер для Windows**

## 📥 Установка

1. Скачай `MyLauncher.exe` из [последнего релиза](https://github.com/Mystiq-Tech-IS/my-launcher/releases/latest).
2. Положи в любую папку.
3. Запусти.

> ⚠ Windows SmartScreen может предупредить — это норма. Нажми **Подробнее → Выполнить в любом случае**.

## ✨ Возможности

- Плитки программ с иконками и обложками
- Категории: Все, Недавние, Игры, Работа, Система, Прочее
- Spotlight-поиск (Ctrl+Alt+Space)
- Пресеты запуска
- Автообновления через GitHub Releases
- Discord Rich Presence
- Мониторинг CPU / RAM / GPU
- Кастомный фон: частицы, градиент, изображение, GIF, видео
- Тёмная и светлая темы

## ⌨ Горячие клавиши

| Комбинация | Действие |
|---|---|
| Ctrl+Alt+L | Показать / скрыть лаунчер |
| Ctrl+Alt+Space | Быстрый поиск |
| Ctrl+T | Переключить тему |
| Ctrl+M | Мини-режим |
| F5 | Обновить статусы |
| F11 | Полноэкранный режим |
